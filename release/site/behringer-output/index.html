Behringer Multichannel Output
Направляет стереосигнал foobar2000 на выбранную пару выходных каналов многоканального аудиоустройства.
v{{VERSION}} foobar2000 2.x macOS · Apple Silicon / Intel
Скачать .fb2k-component с GitHub Releases ↗
v{{VERSION}} · universal · лицензия MIT
// возможности
  • Каждая стереопара показывается отдельным пунктом в меню Output Device.
  • Левый и правый каналы отправляются на выбранную пару: например, FLOW 8 — 1/2 или FLOW 8 — 3/4.
  • Для многоканальных устройств выводит все последовательные пары каналов, которые macOS публикует через CoreAudio.
// установка
  1. Скачайте компонент по кнопке выше.
  2. Если macOS заблокирует файл, откройте Терминал в папке загрузок и снимите карантин: xattr -dr com.apple.quarantine foo_behringer_output.fb2k-component
  3. Откройте компонент двойным щелчком или добавьте его через foobar2000 → Settings → Components. Перезапустите foobar2000.
  4. Откройте меню Output Device и выберите устройство с нужной парой каналов.
// совместимость
  • На Behringer FLOW 8 проверены пары 1/2 и 3/4.
  • XR18, X32 и WING будут отображаться, если подключённое устройство предоставляет выходные каналы через CoreAudio. На этих моделях пока не проверено.
  • Одновременно выводится один стереосигнал на одну выбранную пару.
