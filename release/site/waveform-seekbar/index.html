Waveform Seekbar для foobar2000 (macOS)
Полоса перемотки, которая показывает форму волны трека — как в AIMP.
v{{VERSION}} foobar2000 2.x Apple Silicon / Intel
Скачать foo_wave_seekbar.fb2k-component
v{{VERSION}} · элемент раскладки waveform-seekbar
// возможности
  • Волна строится в фоне и прорисовывается по мере сканирования
  • Показывает пики и средний уровень (RMS), проигранная часть выделена акцентным цветом macOS
  • Перемотка кликом и перетаскиванием, подсказка со временем при наведении курсора
  • Время слева и справа от волны (параметр time=sides)
  • Цвета настраиваются: Settings → Display → Waveform Seekbar
  • Подстраивается под светлую и тёмную тему
// скриншот
// установка
  1. Скачайте файл foo_wave_seekbar.fb2k-component (кнопка выше).
  2. Снимите карантин macOS. Откройте Терминал, перейдите в папку со скачанным файлом и выполните команду ниже.
    Важно

    Без этого macOS может сказать «файл повреждён», потому что плагин не подписан Apple.

    xattr -dr com.apple.quarantine foo_wave_seekbar.fb2k-component
  3. Дважды кликните по файлу или откройте в foobar2000 Preferences → Components и нажмите «+». Перезапустите foobar2000.
  4. Откройте View → Layout → Edit Layout и добавьте строку waveform-seekbar, например над панелью управления.
splitter horizontal style=thin splitter vertical style=thin albumlist playlist waveform-seekbar playback-controls

Чтобы слева и справа от волны показывалось время — прошедшее и общая длительность трека, — допишите к строке параметр time=sides:

waveform-seekbar time=sides

Без параметра волна занимает всю ширину, а время видно только во всплывающей подсказке при наведении.

// известные ограничения
  • Волна не сохраняется на диск и после перезапуска foobar2000 строится заново
  • Каналы L/R не отображаются раздельно
  • Для интернет-радио и потоков без известной длительности волна не строится
