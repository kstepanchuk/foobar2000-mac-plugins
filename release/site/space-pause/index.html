Space Pause для foobar2000

Нажмите пробел в активном окне плеера, чтобы поставить музыку на паузу или продолжить воспроизведение.

v1.1.0foobar2000 2.xmacOS 12+Apple Silicon / Intel
↓ Скачать foo_space_pause-v1.1.0.fb2k-component

// как работает

Пробел переключает паузу и воспроизведение, когда активно окно foobar2000. Назначать клавишу в Keyboard Shortcuts не нужно: foobar2000 для Mac не разрешает назначить одиночный пробел. В текстовых полях пробел остаётся обычным символом.

// установка

  1. Скачайте компонент по кнопке выше.
  2. В foobar2000 откройте Settings → Components, нажмите «+» и выберите скачанный файл.
  3. Перезапустите foobar2000. Теперь пробел переключает паузу, когда активно окно плеера.

Если macOS блокирует компонент из-за карантина, откройте Терминал в папке загрузок и выполните:
xattr -dr com.apple.quarantine foo_space_pause-v1.1.0.fb2k-component
