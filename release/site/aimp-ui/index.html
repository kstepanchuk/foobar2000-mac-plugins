AIMP UI для foobar2000 (macOS)
Интерфейс в стиле AIMP: шапка с обложкой и крупными кнопками, вкладки с оранжевым подчёркиванием, плейлист с группировкой.
v{{VERSION}} foobar2000 2.x Apple Silicon / Intel
Скачать foo_aimp_ui.fb2k-component
v{{VERSION}}
// возможности
Шапка aimp-header
  • Обложка, название и исполнитель, крупные кнопки, громкость, Shuffle и Repeat
Вкладки aimp-tabs
  • С оранжевым подчёркиванием
Плейлист aimp-playlist
  • Группы по исполнителю и альбому, две строки на трек, перетаскивание
Подвал aimp-footer
  • Добавить и удалить треки, быстрый поиск, итог «треков / время / размер»
// скриншот
// установка
  1. Скачайте файл foo_aimp_ui.fb2k-component (кнопка выше).
  2. Снимите карантин macOS. Откройте Терминал, перейдите в папку со скачанным файлом и выполните команду ниже.
    Важно

    Без этого macOS может сказать «файл повреждён», потому что плагин не подписан Apple.

    xattr -dr com.apple.quarantine foo_aimp_ui.fb2k-component
  3. Дважды кликните по файлу или откройте в foobar2000 Preferences → Components и нажмите «+». Перезапустите foobar2000.
  4. Откройте View → Layout → Edit Layout, вставьте раскладку ниже и нажмите Apply.
splitter horizontal style=thin aimp-header waveform-seekbar time=sides aimp-tabs aimp-playlist aimp-footer

Элемент waveform-seekbar — отдельный плагин Waveform Seekbar, его можно убрать из раскладки, если не нужен. Вернуть стандартный вид — View → Layout, выбрав любой встроенный вариант.

// известные ограничения
  • Плагин не подписан Apple, поэтому нужен шаг 2 установки
  • Нет рейтинга звёздочками
